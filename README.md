# Sistema de Gestión de Inventarios y Distribución

## Descripción del proyecto

Este proyecto académico propone el diseño de un sistema de gestión de inventarios y distribución, tomando como contexto organizacional a Coca-Cola FEMSA Colombia.

Su propósito es facilitar el registro de productos, el control de existencias y la administración de pedidos, mediante una solución de software que permita organizar la información relacionada con el inventario y la distribución.

## Objetivo general

Proponer un sistema que permita gestionar de manera organizada los productos, las entradas y salidas de mercancía y los pedidos relacionados con los procesos de inventario y distribución.

## Funcionalidades principales

- Registro y administración de productos.
- Registro de entradas de mercancía.
- Registro de salidas de mercancía.
- Consulta de existencias disponibles.
- Registro y seguimiento de pedidos.
- Generación de informes de inventario.
- Gestión de usuarios y acceso al sistema.

## Tecnologías y herramientas

- Git: control de versiones.
- GitHub: alojamiento y gestión del repositorio.
- Markdown: documentación del proyecto.

## Alcance académico

Este proyecto corresponde a una propuesta académica. No representa un sistema oficial ni afirma describir los procesos internos reales de Coca-Cola FEMSA Colombia.

## Estado del proyecto

En etapa inicial de análisis y documentación de requisitos.
